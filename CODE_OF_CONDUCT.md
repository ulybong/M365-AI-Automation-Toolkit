# Code of Conduct

## Our Pledge

We want this project to be a respectful and productive place for collaboration.

## Expected Behavior

- Be courteous and professional.
- Give constructive feedback.
- Focus on the code and the problem, not the person.
- Keep discussion relevant to the project.

## Unacceptable Behavior

- Harassment, discrimination, or abusive language
- Deliberate disruption of collaboration
- Sharing secrets, credentials, or unsafe instructions
- Repeatedly ignoring project safety or review guidance

## Enforcement

Project maintainers may remove comments, close issues, or restrict participation if behavior is harmful or disruptive.

## Scope

This code of conduct applies to issues, pull requests, discussions, and any project-related interaction.
