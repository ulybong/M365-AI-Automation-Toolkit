# Security Policy

## Supported Versions

This repository is maintained on the current `main` branch.

## Reporting a Vulnerability

If you discover a security issue, do not open a public issue with sensitive details.

Please report security concerns privately through the repository owner or the GitHub security reporting workflow for this repository.

Include:
- A short description of the issue
- Affected file or area
- Steps to reproduce, if safe to share
- Potential impact

## Security Guidance

- Never commit secrets, tokens, certificates, or environment-specific credentials.
- Use least-privilege permissions for all automation.
- Review destructive operations carefully before running them.
- Prefer read-only validation before making changes.
